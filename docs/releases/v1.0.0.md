## English

The first public release of Ozyune — a lightweight native macOS home for `dsh web`.

> Ozyune is an independent project and is not an official DeepSeek application.

### New

- **Native launch** — starts `dsh web` automatically when the app opens; no terminal needed
- **Embedded Web UI** — the dsh Web UI runs inside a native window (WKWebView); no browser tab required
- **Branded startup screen** — live progress while dsh boots, with clear diagnostics if startup fails
- **Clean lifecycle** — quitting Ozyune also stops the dsh process it manages
- **Universal binary** — runs natively on both Apple Silicon and Intel Macs
- **Signed & notarized** — Developer ID signed and notarized by Apple: download, unzip, open. No Gatekeeper warnings

### Requirements

- macOS 14 or later.
- dsh installed separately — Ozyune is only a shell and does **not** bundle the runtime:
  ```bash
  npm install --global @deepseek-ai/dsh
  ```
- Node.js available in your shell environment.

### Installation

1. Download `Ozyune.zip` from the assets below
2. Unzip and move `Ozyune.app` to `/Applications`
3. Launch Ozyune — it boots dsh and loads the Web UI automatically

**Full changelog**: https://github.com/yuzio-ai/ozyune/commits/v1.0.0

## 简体中文

Ozyune 的首个公开版本 —— 一个轻量的原生 macOS 容器，为 `dsh web` 而生。

> Ozyune 是独立项目，并非 DeepSeek 官方应用。

### 新增

- **原生启动** —— 打开 App 自动拉起 `dsh web`，无需使用终端
- **内嵌界面** —— dsh Web UI 直接运行在原生窗口中（WKWebView），不再占用浏览器标签页
- **品牌启动屏** —— dsh 启动过程实时可见，失败时给出明确的诊断信息
- **干净的生命周期** —— 退出 Ozyune 会同时停止它管理的 dsh 进程
- **通用二进制** —— Apple Silicon 与 Intel Mac 均原生运行
- **已签名并公证** —— Developer ID 签名 + Apple 公证，下载解压即可直接打开，无任何安全警告

### 系统要求

- macOS 14 或更高版本。
- 需自行安装 dsh —— Ozyune 只是一个外壳，本身**不内置**运行时：
  ```bash
  npm install --global @deepseek-ai/dsh
  ```
- shell 环境中可用的 Node.js。

### 安装

1. 下载下方 Assets 中的 `Ozyune.zip`
2. 解压后将 `Ozyune.app` 移入「应用程序」
3. 启动 Ozyune —— 它会自动拉起 dsh 并加载 Web 界面

**完整变更**：https://github.com/yuzio-ai/ozyune/commits/v1.0.0
