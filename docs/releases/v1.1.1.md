## English

Ozyune v1.1.1 rebuilds the Notification Preferences pane around modern macOS System Settings
layout, so the window reads like a native settings pane instead of a custom form.

### Changed

- **Grouped surfaces** — the notification settings pane is rebuilt with the hierarchy and rounded
  grouped surfaces of current macOS System Settings, with contrast and legibility holding up in
  both Light and Dark appearances.
- **Permission status pill** — the system permission state is now a compact pill that pairs an
  icon with a semantic colour, so granted / denied / not-determined is readable at a glance.
- **Context-aware primary action** — when permission has been switched off in System Settings,
  the prominent button becomes "Open System Settings…" instead of leading into a dead end.
- **Fixed vertical rhythm** — top-anchored groups with consistent spacing replace the leftover
  spring padding, and the window matches the standard macOS settings size.

### Requirements

- macOS 14 or later.
- dsh installed separately — Ozyune is only a shell and does **not** bundle the runtime:
  ```bash
  npm install --global @deepseek-ai/dsh
  ```
- The first launch asks for notification permission; if nothing ever appears, allow Ozyune in
  System Settings → Notifications.
- Building from source requires code signing (`DEVELOPMENT_TEAM` in `Local.xcconfig`): macOS's
  notification service rejects ad-hoc and unsigned builds, and those builds never see the
  permission prompt.

### Installation

1. Download `Ozyune.zip` from the assets below
2. Unzip and move `Ozyune.app` to `/Applications`
3. Launch Ozyune — it boots dsh and loads the Web UI automatically

**Full changelog**: https://github.com/yuzio-ai/ozyune/compare/v1.1.0...v1.1.1

## 简体中文

Ozyune v1.1.1 把通知偏好设置面板重建为贴近现代 macOS 系统设置的布局，窗口看起来是一个原生的设置面板，
而不是自绘表单。

### 变更

- **分组卡片** —— 通知设置面板改用当前 macOS 系统设置的层级与圆角分组卡片，深色与浅色外观下
  对比度与可读性都成立。
- **权限状态胶囊** —— 系统权限状态改为紧凑胶囊，图标配合语义色彩，允许 / 已拒绝 / 未决定一眼可辨。
- **随情境切换的主操作** —— 当权限已在系统设置中被关闭时，高亮按钮变为「打开系统设置…」，
  而不是引向死路。
- **固定的纵向节奏** —— 分组自上而下锚定、间距统一，替代此前残存的弹簧留白，窗口尺寸与
  macOS 标准设置窗口一致。

### 系统要求

- macOS 14 或更高版本。
- 需自行安装 dsh —— Ozyune 只是一个外壳，本身**不内置**运行时：
  ```bash
  npm install --global @deepseek-ai/dsh
  ```
- 首次启动会请求通知权限；若始终收不到，请在 系统设置 → 通知 中允许 Ozyune。
- 从源码自行构建需要签名（`Local.xcconfig` 中的 `DEVELOPMENT_TEAM`）：macOS 通知服务不接受
  ad-hoc / 无签名构建，这类构建下授权弹窗不会出现。

### 安装

1. 下载下方 Assets 中的 `Ozyune.zip`
2. 解压后将 `Ozyune.app` 移入「应用程序」
3. 启动 Ozyune —— 它会自动拉起 dsh 并加载 Web 界面

**完整变更**：https://github.com/yuzio-ai/ozyune/compare/v1.1.0...v1.1.1
